# Romanian Daily

Офлайн-приложение: 10 слов в день, написание, грамматика, фразы.

## Открыть сейчас

GitHub Pages: https://zholty2011-droid.github.io/romanian-daily/

Самый новый офлайн-файл один HTML (~195 KB) слишком большой для одной заливки через API. Pages пока старая рабочая версия (`index.html` + `app.js`).

Чтобы поставить новую версию на Pages:
1. скачай файл `romanian-daily-offline.html`
2. в GitHub открой `index.html` → карандаш → вставь содержимое целиком → Commit.

Если тест показывает мусор — **Свои слова → Вернуть курс**.
