# Romanian Daily

10 румынских слов в день: перевод, транскрипция, примеры и озвучка.
PWA — работает офлайн и устанавливается на телефон как приложение.

- Сайт: https://zholty2011-droid.github.io/romanian-daily/
- Репозиторий: https://github.com/zholty2011-droid/romanian-daily

## Возможности

- **30 дней, 300 слов** базовой румынской лексики (приветствия, еда, город, транспорт, работа, путешествия, технологии…).
- **Режим урока**: сначала слово и транскрипция, перевод открывается по кнопке — можно попробовать вспомнить самому.
- **Озвучка** через `speechSynthesis` (румынский голос, если он есть в системе).
- **Повторение**: случайные 10 невыученных слов из пройденных дней.
- **Словарь** с поиском по слову, переводу и транскрипции.
- **Прогресс и серия дней** хранятся в `localStorage`.
- **Полный офлайн**: все стили, данные и код — локальные, без CDN. Service worker кэширует приложение.

## Запуск локально

```bash
npm install     # dev-зависимости: tailwindcss, sharp, jsdom
npm run dev     # http://localhost:5173
npm test        # валидация словаря + дымовой тест интерфейса
```

Без `npm install` можно открыть `index.html` через любой статический сервер
(например `python3 -m http.server`) — приложению нужны только файлы из репозитория.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка, мета-теги, подключение `styles.css` и `app.js` |
| `app.js` | Вся логика: состояние, виды, обработчики, загрузка данных |
| `styles.css` | Собранный Tailwind (генерируется, коммитится) |
| `tailwind.css` | Исходник стилей (база + утилиты) |
| `sw.js` | Service worker: офлайн-кэш |
| `manifest.json`, `icon*.png`, `icon.svg` | PWA-манифест и иконки |
| `words-part1.json` … `words-partN.json` | Словарь, 10 слов на день |
| `scripts/` | `serve.mjs` (dev-сервер), `generate-icons.mjs` (PNG из SVG) |
| `tests/` | `validate-data.mjs` (схема словаря), `app.test.mjs` (jsdom-тест UI) |

Tailwind используется как генератор CSS на этапе разработки:
в браузер уходит только готовый `styles.css` (~14 КБ), CDN не нужен.

```bash
npm run build:css     # пересобрать styles.css после правки классов
npm run watch:css     # то же в режиме наблюдения
npm run build:icons   # пересоздать PNG-иконки
```

> В CI есть проверка, что `styles.css` актуален: если классы в разметке изменились,
> а CSS не пересобран, сборка упадёт.

## Формат словаря

Данные лежат в `words-part1.json`, `words-part2.json`, … — приложение грузит паки
по порядку и останавливается на первом отсутствующем файле, поэтому новый пак
добавляется простым созданием `words-part4.json`.

```json
[
  {
    "id": "w001",
    "day": 1,
    "word": "bună",
    "transcription": "бунэ",
    "translation": "привет, здравствуй",
    "examples": [
      { "ro": "Bună ziua!", "transcription": "бунэ зиуа", "ru": "Добрый день!" },
      { "ro": "Bună, ce faci?", "transcription": "бунэ че фачь", "ru": "Привет, как дела?" }
    ]
  }
]
```

Требования (проверяет `npm test`): уникальные `id`, `day` — целое число ≥ 1,
дни идут без пропусков, по 10 слов в дне, у каждого примера заполнены `ro`,
`transcription` и `ru`.

Транскрипция — практическая, кириллицей, для русскоязычного читателя
(упрощённая передача звучания, без знаков ударения).

## Установка на телефон

1. Откройте сайт в Chrome или Safari.
2. Android: меню → «Установить приложение».
3. iPhone: Поделиться → На экран «Домой».
