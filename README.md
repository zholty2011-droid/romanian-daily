# Romanian Daily

10 румынских слов в день: **слова → написание → грамматика → фразы**.
Офлайн-first PWA: устанавливается на телефон и работает без интернета.

- Сайт: https://zholty2011-droid.github.io/romanian-daily/
- Репозиторий: https://github.com/zholty2011-droid/romanian-daily

## Что внутри

**Курс**

- **485 слов / 49 дней** — базовая лексика: приветствия, еда, дом, город, транспорт,
  работа, техника, путешествия, здоровье, деловые фразы.
- У каждого слова — перевод, транскрипция и 2 примера с озвучкой.
- **100 разговорных фраз** (дом / улица) с фильтром по месту.
- **Грамматика** — короткая заметка на каждый из 49 дней + **81 вопрос теста** с пояснениями.

**Режимы**

- **День**: слова → написание (буквенная клавиатура) → грамматика → фразы.
  Порядок шагов иногда перемешивается — так день не становится скучным.
- **Проверка**: тест с выбором варианта (RO→RU и RU→RO, 8/12/20 вопросов),
  карточки, письмо по памяти.
- **Словарь** с поиском, отметками «выучено» и списком ошибок.
- **Свои слова**: импорт из Excel (`.xlsx`), Word (`.docx`), CSV или текста,
  выгрузка шаблона, возврат к базовому курсу.
- Тёмная тема, прогресс и серия дней в `localStorage`.

## Запуск локально

```bash
npm install     # dev-зависимости: jsdom (тесты), sharp (иконки)
npm run dev     # http://localhost:5173
npm test        # валидация данных + дымовой тест интерфейса
```

Без `npm install` приложение тоже работает — достаточно любого статического
сервера (`python3 -m http.server`): в браузер уходят только файлы из репозитория,
никаких CDN.

## Данные

Слова лежат в `words-part1.json`, `words-part2.json`, … — приложение грузит паки
по порядку и останавливается на первом отсутствующем файле, поэтому новый пак
добавляется простым созданием `words-part6.json`.

```json
[
  {
    "id": "1-1",
    "day": 1,
    "word": "bună",
    "translation": "привет / здравствуй",
    "transcription": "бу-н",
    "examples": [
      { "ro": "Bună! Ce mai faci?", "ru": "Привет! Как дела?", "transcription": "бу-н" }
    ]
  }
]
```

Что проверяет `npm test`: уникальные `id` и слова, `day` — целое число ≥ 1, дни
без пропусков, заполненные `ro`/`ru`/`transcription` в примерах и фразах,
корректность вопросов квиза (индекс ответа в диапазоне, есть пояснение).
Отдельно ловится автоген вида «Где autobuz?» — когда румынское слово осталось
в русском переводе.

### Транскрипция

Практическая, кириллицей, для русскоязычного читателя, единым стилем — слитно,
без дефисов (`мулцумеск`, `бунэ`). Её генерирует `scripts/transcribe.mjs`:

```bash
node ./scripts/transcribe.mjs "Bună! Ce mai faci?"   # → бунэ че май фачь
node ./scripts/transcribe.mjs --check                # сверить с имеющимися в данных
node ./scripts/transcribe.mjs --apply                # переписать транскрипции в words-part*.json
```

Правила учитывают румынские дифтонги и мягкость: `ea → я` (dimineața → диминяца),
`c/g` перед `e/i` (`faci → фачь`, `femeie → фемейе`), конечное `-i` (`găti → гэти`,
`ești → ешть`, `ochi → окь`), `â/î → ы` (`câine → кыйне`). Заимствования вроде
`site` заданы исключениями. После правки правил стоит запустить `--check` и
посмотреть расхождения с уже написанным вручную.

## Один файл без установки

`romanian-daily-offline.html` — автономная сборка: стили, скрипт и все данные
внутри (~265 КБ). Открывается двойным кликом, работает по `file://` и без сети.

```bash
npm run build:offline   # пересобрать из исходников
```

Файл генерируется: править надо `index.html`, `app.js`, `styles.css` и JSON с
данными, затем пересобирать. Актуальность сборки проверяет CI.

2. Android: меню → «Установить приложение».
3. iPhone: Поделиться → На экран «Домой».
