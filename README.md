# Romanian Daily

10 румынских слов в день. PWA для телефона.

Репозиторий: https://github.com/zholty2011-droid/romanian-daily

## GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch `main` / root.

Сайт: https://zholty2011-droid.github.io/romanian-daily/

## Установка на телефон

1. Открой сайт в Chrome / Safari.
2. Android: меню → Установить приложение.
3. iPhone: Поделиться → На экран «Домой».
