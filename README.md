# Romanian Daily

Офлайн-приложение: 10 слов в день, написание, грамматика, фразы.

## Открыть

- GitHub Pages: https://zholty2011-droid.github.io/romanian-daily/
- Или скачай `index.html` и открой на телефоне (работает без интернета).
- На iPhone: Safari → Поделиться → На экран «Домой».
- На Android: Chrome → Меню → Установить приложение.

## Что внутри

- Курс 30 дней + импорт своих слов (Excel / Word / CSV)
- День: слова → написание (буквы + подсказки) → грамматика → фразы
- Тест без повторов и мусора в вариантах (8/12/20 вопросов)
- Тёмная тема, голос, экзамен

Если тест показывает мусор — **Свои слова → Вернуть курс**.
